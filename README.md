# Hi, I'm Dennis Peter Munyao 
## My Coding Journey
<details>
  <summary>🎯 <strong>My Engineering Journey</strong></summary>

My passion for technology began in high school. At university I started coding with **C++**, where I discovered the power of logical problem-solving. That foundation led me to web development, where I gravitated toward **backend systems** and **scalable architecture**.

Today I build full-stack applications across **React, Next.js, Angular, NestJS, .NET, Django and FastAPI**, deployed on **Linux, Docker, GCP and AWS**. Areas I've worked in include:

- System design and API architecture
- Microservices and event-driven systems
- Message queues (RabbitMQ, Pub/Sub)
- Bulk email campaign platforms
- Real-time applications with WebSockets
- API backends with authentication, rate limiting and monitoring

I keep sharpening my skills in **distributed systems**, **cloud infrastructure** and **performance optimization**.

</details>
